# «Принятие»

Учебный сервис по оказанию психотерапевтической помощи. Проект объединяет
объектную модель предметной области и JSON-хранилище (ПР3) с веб-интерфейсом
на Django. В ПР6 HTML перенесён из Python-кода во встроенный язык шаблонов
Django (DTL).

## Технологии

- Python 3.11+
- Django 5.2
- JSON-файлы для хранения данных
- HTML5, CSS и Bootstrap 5.3 через CDN
- pytest и flake8

## Страницы

- `/` — главная страница и навигация.
- `/specialists/` — список специалистов.
- `/specialists/<specialist_id>/` — сведения о специалисте.
- `/appointments/` — список записей и их статусы.
- `/appointments/<appointment_id>/` — сведения о записи.
- Несуществующие URL и ID возвращают страницу с HTTP 404.

Именованные маршруты сгруппированы в пространства имён `homepage`,
`specialists` и `appointments`; ссылки в шаблонах формируются через `{% url %}`.

## Модель и данные

`Specialist` хранит имя, специализацию и стаж; метод `is_experienced()`
проверяет стаж. `Appointment` содержит ссылку на объект `Specialist`, имя
клиента, дату и статус; метод `cancel()` отменяет запись.

Файлы `data/specialists.json` и `data/appointments.json` являются источником
данных. В JSON запись хранит `specialist_id`; загрузчик связывает его с
объектом специалиста. Django ORM, формы и аутентификация не используются.

## Django-шаблоны и статика

Общий каркас находится в `templates/base.html`, навигация — в
`templates/includes/navigation.html`. Страницы приложений используют DTL:
`extends`, `block`, `include`, циклы, условия и фильтры. Данные передаются из
views через контекст, ссылки формируются именами маршрутов. Стили, логотип и
скрипт текущего года находятся в `homepage/static/homepage/` и подключаются
через `{% static %}`. Навигация, карточки и списки перестраиваются для телефонов
и планшетов.

## Запуск

Из корня проекта создайте и активируйте виртуальное окружение, затем выполните:

```powershell
python -m pip install -r requirements.txt
python manage.py check
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Для этого учебного проекта команда
`migrate` не требуется: прикладные данные хранятся в JSON, а база Django
отключена.

## Проверки

```powershell
python -m pytest -v
python -m flake8 .
```
